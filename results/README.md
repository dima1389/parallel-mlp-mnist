# Benchmark Results

This directory stores all outputs generated by benchmark and training runs. Each run produces a self-contained timestamped folder with logs, CSVs, and plots together. Contents are generated artifacts and are not committed to the repository.

## Directory Structure

Each run creates a single folder under `results/`:

```
results/
  benchmark_20260409_084402/        ← full benchmark run
    logs/
      master.log                    ← script progress output
      seq_small_network_run1.log    ← per-run training logs
      omp_small_network_2t_run1.log
      mpi_small_network_4p_run1.log
      plot_results.log              ← plot generation log
      ...
    tables/
      summary.csv                   ← aggregated per-run metrics (18 columns)
      all_epochs.csv                ← consolidated per-epoch time series
      epochs/                       ← individual per-run epoch CSVs
        seq_small_network_run1_epochs.csv
        omp_small_network_2t_run1_epochs.csv
        ...
    plots/
      speedup_small_network.png     ← speedup bar charts
      exec_time_small_network.png   ← execution time comparison
      throughput_small_network.png  ← throughput scaling
      training_loss_small_network.png
      accuracy_vs_time_small_network.png
      epoch_time_boxplot_small_network.png
      epoch_time_scaling_small_network.png
      ...

  train_seq_small_network_20260408_233307/  ← single-training run
    logs/
    tables/
    plots/
```

### Run Folder Naming

| Pattern | Source |
|---------|--------|
| `benchmark_<YYYYMMDD_HHMMSS>/` | `Run Full Benchmark` task |
| `test_benchmark_<YYYYMMDD_HHMMSS>/` | `Run Quick Test Benchmark` task |
| `train_<impl>_<config>_<YYYYMMDD_HHMMSS>/` | `Train Sequential`/`Train OpenMP`/`Train MPI` tasks |

## Build Logs

Build logs are written to `results/logs/` (top-level, not inside run folders):

| Log File | Source |
|----------|--------|
| `build_all.log` | `Build All` task |
| `build_seq.log` | `Build Sequential` task |
| `build_omp.log` | `Build OpenMP` task |
| `build_mpi.log` | `Build MPI` task |
| `clean_build.log` | `Clean Build` task |

## Summary CSV Schema

`tables/summary.csv` contains one row per (config, implementation, parallelism, run) combination.

| Column | Type | Description |
|--------|------|-------------|
| `config` | String | Network configuration name (e.g., `small_network`) |
| `implementation` | String | Training variant: `sequential`, `openmp`, or `mpi` |
| `parallelism` | Integer | Number of threads (OpenMP) or processes (MPI); `1` for sequential |
| `run` | Integer | Trial number (1-based) |
| `epochs` | Integer | Number of training epochs |
| `batch_size` | Integer | Mini-batch size |
| `learning_rate` | Float | Learning rate |
| `total_params` | Integer | Total trainable parameters |
| `total_time_sec` | Float | Total training wall-clock time |
| `avg_epoch_time_sec` | Float | Average wall-clock time per epoch |
| `min_epoch_time_sec` | Float | Minimum epoch time |
| `max_epoch_time_sec` | Float | Maximum epoch time |
| `stddev_epoch_time_sec` | Float | Standard deviation of epoch times |
| `final_loss` | Float | Training loss after last epoch |
| `final_accuracy` | Float | Test accuracy after last epoch |
| `best_accuracy` | Float | Best test accuracy achieved |
| `best_accuracy_epoch` | Integer | Epoch where best accuracy was achieved |
| `throughput_samples_per_sec` | Float | Training throughput |

## Consolidated Epoch CSV Schema

`tables/all_epochs.csv` contains one row per (config, implementation, parallelism, run, epoch).

| Column | Type | Description |
|--------|------|-------------|
| `config` | String | Network configuration name |
| `implementation` | String | Training variant |
| `parallelism` | Integer | Thread/process count |
| `run` | Integer | Trial number |
| `epoch` | Integer | Epoch number |
| `train_loss` | Float | Training loss for this epoch |
| `test_accuracy` | Float | Test accuracy after this epoch |
| `epoch_time_sec` | Float | Wall-clock time for this epoch |
| `cumulative_time_sec` | Float | Cumulative training time up to this epoch |

## Generated Plots

All plots are saved as PNG files in the `plots/` subdirectory. They are auto-generated at the end of each training/benchmark run.

### From summary.csv

| Plot | File | Description |
|------|------|-------------|
| Speedup bars | `speedup_<config>.png` | Speedup relative to sequential baseline |
| Execution time | `exec_time_<config>.png` | Grouped bar chart comparing implementations |
| Throughput scaling | `throughput_<config>.png` | Throughput vs parallelism level |

### From all_epochs.csv

| Plot | File | Description |
|------|------|-------------|
| Training loss | `training_loss_<config>.png` | Loss vs epoch, overlaid per implementation |
| Accuracy convergence | `accuracy_vs_time_<config>.png` | Accuracy vs wall-clock time |
| Epoch time distribution | `epoch_time_boxplot_<config>.png` | Box plots of epoch times |
| Epoch time scaling | `epoch_time_scaling_<config>.png` | Mean epoch time vs parallelism |
